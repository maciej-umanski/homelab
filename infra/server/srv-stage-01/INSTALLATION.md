# Installation

1. Install [Debian 13](https://www.debian.org) on the system
2. During installation configure:
    - Hostname: `srv-stage-01`
    - Domain: `home.arpa`
    - Locale: `en_US.UTF-8`
    - Keymap: `pl`
    - Timezone: `Europe/Warsaw`
    - User: `sysadmin`
    - Tasksel: **default system utilities**, **SSH Server** and **no desktop environment**
