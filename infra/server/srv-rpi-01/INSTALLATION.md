# Installation

1. Install `Raspberry Pi OS Lite (32-bit)` on the SD card
   using [Raspberry Pi Imager](https://www.raspberrypi.com/software/).
    - Hostname: `srv-rpi-01`
    - Locale: `en_US.UTF-8`
    - Keymap: `pl`
    - Timezone: `Europe/Warsaw`
    - User: `sysadmin`
    - Enable SSH during installation
    - Connect to Wi-Fi during installation
